# Exploratory activity: investigate order recovery

## Mission

Explore the Create Order form and confirmation to discover unexpected behaviour
or confusing feedback when amounts and discounts are edited, submitted or
corrected.

## Focus

- validation and readable feedback;
- recovery after invalid input;
- consistency after view, back and refresh;
- visible state and saved-order retrieval.

## Data and environment

Record the browser, application revision and values used. Start with a fresh
local application. The scripted happy path already uses 1250 cents and 10%.
