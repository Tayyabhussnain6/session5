# Session 5 — Voluntary Mastery Self-Check

This self-check is **optional and non-graded**. Score each statement: **0** not yet; **1** with support; **2** independently; **3** I can explain or transfer it to a new example.

1. I can distinguish system, end-to-end, acceptance and exploratory testing purposes without treating them as four separate boxes.
2. I can turn a user goal into observable criteria and name an independent source for the expected result.
3. I can map a journey from starting state through actions and boundaries to a visible or saved outcome.
4. I can explain why a confirmation heading alone is weaker evidence than checking the price and retrieving the saved order.
5. I can identify what pytest, Playwright, a browser context, the local Flask app and a fixture each do in this practice.
6. I can use meaningful locators and explain Playwright's waiting and web-first assertions without relying on a fixed sleep.
7. I can distinguish an intentional unfinished-test failure from an application defect.
8. I can record exploratory actions, observations, expected rules, questions and follow-up without inventing a defect.
9. I can state what one local passing browser journey supports and what it leaves untested.
10. I can adapt the method to a real browser, command-line or service workflow in my selected project and label unrun work as proposed.
11. I can justify an Accept, Modify or Reject decision about an AI testing suggestion using project evidence.

Choose one or two statements below level 2 for further practice. You do not need to submit this self-check unless instructed in **itslearning**.
